# Native UI icons

The ic_ui_* Android VectorDrawable resources use the original path data from Google's Material Design outlined icons (24px). Source: https://github.com/google/material-design-icons/tree/master/src

Home, account_circle, search, notifications and local_offer form TolMol's five-tab native navigation. Arrow_back, favorite/favorite_border, share, more_vert, chevron_right, info and chat_bubble_outline support product details. No icon font, web view or bitmap is used.
